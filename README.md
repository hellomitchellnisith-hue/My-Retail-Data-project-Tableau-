# 🛒 Retail Data Analysis — Tableau

## 📊 Project Overview

This project presents an interactive **Retail Analytics Dashboard developed using Tableau**. The dashboard transforms retail data into meaningful visual insights, helping analyze sales performance, product trends, customer segments, regional performance, and key business KPIs.

The goal of this project is to demonstrate how data visualization can be used to identify trends, understand business performance, and support data-driven decision-making.

---

## 🎯 Objectives

* Analyze overall retail sales performance
* Identify top-performing products and categories
* Understand customer segments and purchasing patterns
* Analyze regional and geographic performance
* Track important business KPIs
* Create interactive and user-friendly dashboards
* Present complex retail data through clear visualizations
